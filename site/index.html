Software Foundations · VFA / SearchTree

Two tree traversals. One proof.

A simple traversal joins lists with append. A faster version threads an accumulator. Prove that they return the same elements, for every tree and every accumulator:

theorem fast_elements_helper (t : Tree V) (acc : List (Nat × V)) :
    fastElements t acc = elements t ++ acc := by
  waterfall [elements, fastElements, List.append_assoc]

Waterfall finds an induction proof that covers recursive calls with changed accumulators. Supply the two definitions and append associativity; the tactic connects the proof steps.

Show the complete, runnable Lean example 
import Waterfall

inductive Tree (V : Type) where
  | empty
  | node (left : Tree V) (key : Nat) (value : V) (right : Tree V)

def elements : Tree V → List (Nat × V)
  | .empty => []
  | .node left key value right => elements left ++ (key, value) :: elements right

def fastElements : Tree V → List (Nat × V) → List (Nat × V)
  | .empty, acc => acc
  | .node left key value right, acc =>
      fastElements left ((key, value) :: fastElements right acc)

theorem fast_elements_helper (t : Tree V) (acc : List (Nat × V)) :
    fastElements t acc = elements t ++ acc := by
  waterfall [elements, fastElements, List.append_assoc]

One engine. Two ways to search.

Backtracking search

The default mode keeps alternatives available when a later obligation fails. It searches whole proof continuations, including pending sibling goals.

ACL2-inspired commitment

Committed mode accepts local progress, tries ordinary work before induction, and can return to the original conjecture once per trial. It prunes alternatives and can miss proofs that search finds.

Both modes use the same inference operations and produce proofs checked by Lean. Commitment is an alternative search behavior, with no universal speed advantage.

Waterfall is strongest on inductive data with usable recursive definitions and helper lemmas. Missing lemmas, difficult mutual induction and unsuitable ordering can still prevent closure. Lemma discovery is separate; the package does not implement all of ACL2’s reasoning machinery.
